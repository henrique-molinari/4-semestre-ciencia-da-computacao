# Aula 14/08/2026 — Desenvolvimento de Interfaces de Usuário para Web

Introdução à comunicação cliente-servidor, protocolo HTTP e estrutura
básica de páginas HTML, com a primeira entrega prática em três páginas
interligadas.

## Conteúdo

- `index.html`, `pagina2.html`, `pagina3.html` — páginas HTML da entrega
- `assets/images/` — imagens usadas nas páginas
- [anotacoes-de-aula.md](./anotacoes-de-aula.md) — anotações da aula: arquitetura cliente-servidor, HTTP, portas, DNS, front-end/back-end e protocolos (SMTP, IMAP, FTP)
