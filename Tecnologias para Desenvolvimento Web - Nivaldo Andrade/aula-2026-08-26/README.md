# Aula 26/08/2026 — Tecnologias para Desenvolvimento Web

Continuação do projeto `pj_pet_get`: controllers, validação de usuário e
organização das rotas.

## Conteúdo

- `pj_pet_get/controllers/userController.js` — regras de negócio do usuário
- `pj_pet_get/helpers/userValidator.js` — validação dos dados de entrada
- `pj_pet_get/models/Users.js` — model de usuário
- `pj_pet_get/db/conn.js` — conexão com o banco de dados
- `pj_pet_get/routes/userRouters.js` — rotas de usuário
- [anotacoes-de-aula.md](./anotacoes-de-aula.md) — anotações da aula: métodos HTTP, validação com express-validator, middlewares e criptografia de senha com bcrypt

## Como rodar

```bash
cd pj_pet_get
npm install
npm start
```
