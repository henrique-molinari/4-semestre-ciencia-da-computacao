# Aula 12/08/2026 — Tecnologias para Desenvolvimento Web

Estrutura padrão de projeto MVC em Node.js/Express.

## Conteúdo

- `server.js` — ponto de entrada do servidor
- `src/app.js` — configuração da aplicação Express
- `src/controller/`, `src/models/`, `src/routers/` — estrutura MVC inicial

## Como rodar

```bash
npm install
npm start
```
