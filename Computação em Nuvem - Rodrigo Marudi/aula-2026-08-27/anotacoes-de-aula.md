A anatomia da Nuvem - 5 caracteristicas essenciais estabelecidas pelo NIST

- Autosserviço sob demanda
- Amplo acesso a rede
- Pool de recursos
- Elasticidade rápida
- Serviços mensuráveis

IaaS, PaaS e SaaS
- Iaas: Você cuida de aplicações, dados e SO
- PaaS: Você cuida dos dados e SO
- Saas: Você não cuida de nada, apenas usufrui o sistema

4 Tipos de Nuvem:

- Nuvem publica: Arquitetura Multi-inquilino(multi-tenant), Modelo OPEX, Escalabilidade infinita
- Nuvem privada: Arquitetura de Locatário Unico(single-tenant), Controle e Soberania, Segurança e Conformidade, Modelo CAPEX
- Nuvem hibrida: Flexibilidade Arquitetural, Cloud Bursting, Complexidade (mesclagem: uso de nuvem publica para enviar dados e uso de nuvem privada para receber dados)
- Nuvem comunitária: Custos divididos, conformidade especifica, administração (uso por varias sedes com uma unica logica) ex: um consórcio de hospitais utilizando uma mesma infra, dividido o custo de operação da OPEX
