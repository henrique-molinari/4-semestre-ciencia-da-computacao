# Aula 10/08/2026 — Integração de Dados

Primeiros testes de leitura, gravação e integração de dados em Python.

## Conteúdo

- `testepandas.py`, `testepandas2.py` — leitura e manipulação de dados com pandas
- `testeSqlLite.py` — gravação/consulta em banco SQLite
- `testeTinyDB.py` — uso do TinyDB (banco de documentos em JSON)
- `dados.csv`, `dados.json`, `teste.json` — arquivos de dados de apoio
- `integracao_dados.db` — banco SQLite gerado durante a aula
